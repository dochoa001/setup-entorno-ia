# Plantillas — biblioteca reutilizable

Aquí vive todo lo que se reutiliza en el resto del sistema. Se divide en:

- `habilidades/` — instrucciones que la IA puede ejecutar a petición (archivar minuta,
  revisión semanal, preparar seguimiento…).
- `agentes/` — agentes con un propósito fijo (ej. la vista única de pendientes).
- `formatos/` — los moldes base de los documentos (ficha de persona, pendientes, minuta,
  evaluación, proyecto, cliente).

Cuando crees algo nuevo que sirva en varios lados, guárdalo aquí para no repetirte.
