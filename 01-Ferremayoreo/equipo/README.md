# Equipo

Una carpeta por persona: `nombre-apellido/`. Dentro de cada una:

- `ficha.md` — contexto de la persona.
- `pendientes.md` — lo que le debo / me debe.
- `seguimiento/` — minutas (una por junta, `AAAA-MM-DD-tema.md`) y evaluaciones.

Para dar de alta a alguien nuevo, copia `_ejemplo-persona/` y renómbrala.
