# Consultoría (clientes de Joaquín)

Una carpeta por cliente. Dentro de cada cliente:

- `wiki/` — conocimiento del cliente (reemplaza a una carpeta de "contexto": la wiki lo cubre).
- `recursos/` — entregables para ese cliente.
- `adicionales/` — todo lo demás que no cae en las anteriores.
- su propio `README.md` y `AGENTS.md`.

Para dar de alta un cliente nuevo, copia `_ejemplo-cliente/` y renómbrala.
